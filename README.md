## Paycheck Ledger

A paycheck budgeting app that splits each paycheck into spending
envelopes and tracks what's left in each until the next payday, in two
versions:

- [`paycheck-budget-app/`](./paycheck-budget-app) — a single HTML file,
  no build step, works by opening it in any browser.
- [`paycheck-budget-angular/`](./paycheck-budget-angular) — the same app
  rebuilt as an Angular project, for anyone using this repo to learn
  Angular.
